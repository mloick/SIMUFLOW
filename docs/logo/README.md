# Logo SimuFlow : le chemin en S

## L'histoire

SimuFlow est né d'un constat de chef de projet : un process dessiné sur un schéma a l'air simple, mais dans la réalité il n'avance jamais en ligne droite. Une demande part d'un point, passe d'un acteur à l'autre, tourne, revient parfois en arrière, et c'est souvent dans ces virages que tout se bloque : une impasse, une décision sans issue, un délai oublié.

Le logo raconte ce trajet en un seul trait :

- **Le point de départ** (bleu marine) : la demande qui déclenche le process, comme un ticket qui vient d'être ouvert.
- **Le chemin en S** (bleu SimuFlow) : le parcours du process, avec ses deux virages. C'est aussi le **S** de SimuFlow et de Simulation.
- **Les virages arrondis** : un process bien conçu passe ses tournants sans se coincer. C'est exactement ce que l'app vérifie.
- **La flèche d'arrivée** : le process mené jusqu'au bout. Chaque simulation vise ce moment.

Le message du logo : *suivez le chemin avant de le construire*. SimuFlow vous fait parcourir votre process pas à pas, virage après virage, pour arriver à la flèche sans mauvaise surprise.

## Les règles

| Élément | Valeur |
| --- | --- |
| Bleu SimuFlow (chemin, flèche, « Simu ») | `#007ec5` |
| Bleu marine (point de départ, « Flow ») | `#0b2540` |
| Fond de l'icône | Blanc `#ffffff`, bordure `#d5e1ec` |
| Police du nom | Inter, graisse 800 |

- Garder le trait d'un seul tenant, sans le couper ni changer ses virages.
- Sur fond sombre, utiliser l'icône (carré blanc), pas le symbole seul.
- Taille minimale de l'icône : 29 px, la taille d'une icône dans les réglages de l'iPhone.
